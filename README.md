# 老美大战倭寇

支持电脑和手机浏览器的三维射击小游戏。当前版本为 V18，包含可选 Q 版英雄、武器拾取与切换、手雷、六个战场及 26 关固定战役。新增岛链全景转场、自然灾害和远近战日本兵。最终结算展示胜利图片，并根据实际战斗用时奖励得分。死亡和通关结算均可提交昵称与战绩，进入全网共享的“抗日榜单”。

## 目录

- `work/river-game/`：游戏源码、依赖清单及构建脚本。
- `outputs/cloudflare-pages/`：当前版本的页面、资源与排行榜接口 `_worker.js`。
- [最新 Cloudflare 部署包](outputs/laomei-dazhan-wokou-cloudflare.zip?raw=true)：可直接上传的完整 ZIP。

## 本地运行

需要 Node.js 22.13 或更高版本，推荐 Node.js 24。

```powershell
cd work/river-game
npm ci
npm run build
node server.mjs
```

浏览器打开 `http://127.0.0.1:4173/`。静态资源已随仓库提供，无需重新下载纹理。

本地服务使用 `.local/leaderboard.sqlite` 持久保存本地榜单，与线上 D1 数据隔离，该目录不会提交或打包。可通过环境变量 `PORT` 改端口，通过 `LEADERBOARD_DATABASE` 指定本地数据库路径。

方向键或 WASD 移动并控制朝向，空格沿当前朝向射击，停止移动后保持朝向。数字 1 至 4 切换武器，G 投掷手雷，E 使用英雄技能，Shift 沿移动方向闪避，静止时沿朝向闪避，P 暂停。转场可点击箭头或按 Enter 跳过。最终战紧急支援就绪时按 N 召唤核弹。

手机访问会自动显示左下摇杆，拖动控制移动速度与射击朝向，松手停止移动并保持朝向。右下射击按钮支持按住连射，可与摇杆同时操作；点按背包切换武器，点按手雷、闪避和英雄技能按钮释放能力。横竖屏均有独立布局，切到后台时自动暂停。手机默认使用流畅画质，画质偏好与电脑端分别保存。

手机战斗界面压缩状态信息与小地图，武器栏仅显示已获得的武器，空弹武器保留为灰色。射击按钮为 68 像素，手雷、闪避和技能按钮为 48 像素；英雄配置、画质和声音入口位于暂停菜单，紧急核弹以右侧支援按钮出现。电脑保持原有界面布局。两端均按玩家控制的朝向射击，不提供鼠标瞄准或自动锁敌。

## V18 战役

- 第 1 至 5 关海边登陆，第 6 至 10 关丛林作战，第 11 至 15 关山地打击，第 16 至 20 关城市巷战，第 21 至 25 关富士山下猛攻，第 26 关皇宫大决战。
- 按全局关卡编号，每 3 关出现鬼子头目，每 5 关出现日本兵指挥官；第 15 关优先执行每 5 关规则。首领在本关普通敌人清除后登场，战前提供 22 点生命恢复和步枪补给。
- 最终战由鬼子天皇和两名日本兵指挥官共同守卫。三个目标全部击败才进入胜利；低血量核弹支援可以同时击破剩余首领，保留皇宫崩塌和胜利图片结算。
- 日本兵和指挥官具有定向瞄准、短连射、换弹破绽和军刀攻击。射线预警提前锁定方向，飞行子弹可躲避，掩体能挡子弹，手雷能打断攻击；多名首领错开起手时间。
- 六次章节转场使用自行绘制的岛链三维地形，首章乘艇登陆，后续乘车推进，再切入实际战场全景。转场、暂停和切到后台均不增加战斗用时。
- 海岸有海啸，丛林、山地及城市有地震，富士山有喷发与流动熔岩。普通关卡有 30% 概率安排灾害，富士山为 45%，首关与皇宫不出现；每关最多一次，同关重试保留抽取结果。被选中的关卡在开战 28 至 54 秒后开始 8 秒预警，并标记附近可直达的安全区；区外玩家与敌人持续受伤，首领受到较低比例伤害。
- 富士山新增山脊、积雪、火山口和喷发烟尘；皇宫强化御殿、瓦顶、回廊、石阶、护城河和松庭；其他场景补充灯塔、河流、山林、钟楼和旧电车。
- 敌人总量增加约 10% 至 27%，普通敌人生命小幅上调，首领生命提高约 24%，敌人攻击随关卡增加 6% 至 15%。同屏上限仍为 14，普通远程兵最多 3 名，移速与出招预警保持原有节奏。日本兵与指挥官提前 1.3 至 1.5 秒预警，射击后有 3 至 3.2 秒换弹窗口；首领失衡或恢复时受到的子弹伤害约为常态的 1.45 倍，保留闪避、掩体和手雷打断的反击空间。

手枪、步枪、霰弹枪单颗弹丸和狙击枪基础伤害分别为 20、17、15、72。武器每级强化增加 5% 伤害，最高 +10 为 50%；赤焰战甲的超载射速提升为 50%，手雷中心伤害为 170，继续保留范围伤害、击退与打断。熊猫的震荡伤害独立于子弹破绽倍率，避免技能异常叠加。

开局配备无限子弹手枪和 2 枚手雷，第一关第 2 次击杀保留步枪补给。普通武器随机掉率为 22%，连续 6 次击杀未掉落时提供保底，地面最多保留 5 件武器。普通敌人的手雷掉率为 6%，前 6 关每关最多随机掉落 1 枚，后续每关最多 2 枚；普通章节首领另有手雷奖励。携带和地面待拾取的手雷合计最多 3 枚，满额时不再生成。

## Cloudflare Pages

首次配置时，在同一 Cloudflare 账号内创建 D1 数据库 `kangri-leaderboard`，进入现有 Pages 项目的 Settings → Bindings，添加生产环境的 D1 绑定，变量名必须为 `LEADERBOARD_DB`，数据库选择 `kangri-leaderboard`。此配置只需做一次。

下载上面的部署包，在同一个 Pages 项目中新建生产部署并上传 ZIP。入口 `index.html`、接口 `_worker.js` 和路由 `_routes.json` 均位于压缩包根目录。首次打开结算榜单时会自动创建 `leaderboard_scores` 表及排名索引，无需执行 SQL。后续更新 ZIP 会保留 D1 内的成绩。

V18 首次访问榜单时会通过 D1 原子批处理迁移原有的 16 关约束至 26 关，保留历史成绩及索引，数据库绑定不需要改变。

ZIP 直传使用 Pages 的 `_worker.js` 高级模式，不依赖控制台编译 `functions` 目录。只有 `/api/*` 请求进入接口，游戏页面和美术资源仍直接通过静态资源服务加载。

从 Git 仓库部署时，框架预设选择 None，仓库根目录保留默认设置，构建输出目录为 `outputs/cloudflare-pages`。

仓库已包含静态构建结果，也可使用以下构建命令更新页面：

```sh
npm --prefix work/river-game ci && npm --prefix work/river-game run build
```

## 排行榜规则

榜单展示前 50 名，按总分降序排列，同分时用时更短者优先。通关总分为基础战绩加时间奖励，死亡结算使用当时的基础战绩。同一浏览器通过随机玩家标识保留最高成绩，再次提交可以更新昵称；清除浏览器数据或更换设备会生成新的玩家标识，昵称不作为登录凭证。

接口在 `GET /api/leaderboard` 和 `POST /api/leaderboard`，使用绑定访问 D1，不在前端保存数据库凭据。服务端检查昵称、关卡、得分上限和请求大小，并重新计算时间奖励。战斗数据仍由客户端上报，这是一份休闲游戏排行榜，不是能够防止修改客户端作弊的竞技认证系统。

## 资源来源

场景纹理来源记录在 `outputs/cloudflare-pages/assets/sources.json`。第三方库许可见 `outputs/cloudflare-pages/LICENSES.txt`。

人物与主要建筑保留程序化风格化模型和原有比例，画面采用自然配色、暖色日光与冷色环境补光。皮肤、布料、毛发、皮革、涂装与金属分别使用缓存纹理，颜色、凹凸和粗糙度独立处理，修正过强的凹凸与皮肤布纹。人物补充装甲接缝、制服口袋和装备细节，士兵加入膝关节步态；车辆补充反光车窗、轮胎、轮眉、车身板缝和灯具，房屋改善贴图尺度、窗框、窗台、外露钢筋与排水管，皇宫屋瓦贴合弯曲屋面。

沙地、泥土与岩石使用各自的 CC0 纹理与匹配法线，改善道路边缘、近岸水色、山体雪线和皇宫石材细节。登陆艇、电车和转场车辆沿用同一套材质处理，帐篷屋面增加轻微垂坠。

纹理随静态资源提供，游戏运行时无需访问外部素材网站。材质复用、场景合批、空间剔除、粒子池和手机分辨率预算均保留，未增加实时全局光照或全屏环境遮蔽等重型效果。
